# Android 无线调试连接

## 触发场景

当用户表达以下意图时自动激活：
- "无线连接手机"

---

## 执行流程

### 第一步：先让用户选择无线连接方式

当用户说“无线连接手机”时，先不要直接进入连接命令，而是先向用户说明两种可选方式，并让用户选择。
**除这一步以外，后续默认尽量直接执行命令并汇报结果，减少不必要的来回确认。**

> 目前有两种无线连接方式：
>
> 1. **Android 11 及以上无线调试配对码**
>    - 适合系统自带的无线调试功能
>    - 先配对，再连接
>
> 2. **USB 连接后切换到 5555 端口**
>    - 先用 USB 连上手机
>    - 再执行 `adb tcpip 5555`
>    - 然后拔掉 USB，改用无线连接
>
> **请告诉我你要使用哪一种方式**：
> - 回复 **"1"**、**"配对码"**、**"Android11"** → 走方式一
> - 回复 **"2"**、**"USB"**、**"5555"** → 走方式二

---

### 第二步：根据用户选择进入对应流程

#### 场景 A：Android 11 及以上无线调试配对码

**由 AI 尽量自动引导、自动执行命令。**

##### 1. 确认前置条件
如果上下文里已经明确满足这些条件，就不要重复询问；只在信息缺失时再提示用户补充：
- 手机和电脑连接到 **同一个 WiFi 网络**
- 手机已开启 **开发者选项**
- 手机上已开启 **无线调试**

##### 2. 引导用户提供配对信息
> **请按以下步骤操作**：
>
> 1. 手机进入「设置」→「开发者选项」→「无线调试」
> 2. 点击「使用配对码配对设备」
> 3. 查看显示的 **配对 IP:端口** 和 **配对码**
>
> **请把配对信息一次性发给我**（格式：`配对IP:配对端口 配对码`，例如：`192.168.1.100:37123 ABCD123`）

##### 3. AI 执行配对命令
等待用户提供配对信息后，AI 执行：
```bash
adb pair <配对IP>:<配对端口>
```

然后输入用户提供的配对码。
配对成功后，**不要再额外确认**，直接继续下一步连接。

##### 4. 引导用户提供连接信息
配对成功后，向用户询问：
> 配对成功！现在请查看无线调试**主界面**（不是配对界面）显示的 **IP 和端口**，发给我进行连接。
>
> **格式**：`192.168.1.100:5555`

##### 5. AI 执行连接命令
```bash
adb connect <用户提供的IP>:<用户提供的端口>
```

##### 6. AI 验证连接
```bash
adb devices
```

向用户报告最终连接状态。如果失败，再按错误信息决定是否需要用户补充信息。

---

#### 场景 B：USB 连接后切换到 5555 端口

**由 AI 尽量自动引导、自动执行命令。**

##### 1. 确认前置条件
如果上下文里已经明确满足这些条件，就不要重复询问；只在信息缺失时再提示用户补充：
- 手机和电脑连接到 **同一个 WiFi 网络**
- 手机已开启 **开发者选项**
- 手机已开启 **USB 调试**
- 手机已通过 **USB 数据线** 连接到电脑

##### 2. 先检查 USB 连接是否正常
```bash
adb devices
```

如果设备未正常显示，优先直接给出排查建议；只有在确实需要用户配合时再让用户操作。

##### 3. 切换到 5555 端口
```bash
adb tcpip 5555
```
执行后如果命令报错，直接把错误结果告诉用户，并引导用户检查 USB 连接、授权和设备状态。

##### 4. 引导用户拔掉 USB 并提供手机 IP
向用户说明：
> 现在请拔掉 USB 数据线，然后在手机当前 WiFi 网络下查看手机 IP 地址，发给我。
>
> **格式**：`192.168.1.100`

##### 5. AI 执行无线连接命令
等待用户提供手机 IP 后，AI 执行：
```bash
adb connect <用户提供的IP>:5555
```
如果可能，优先直接尝试连接一次；只有在无法连接时再要求用户重新确认 IP。

##### 6. AI 验证连接
```bash
adb devices
```

向用户报告最终连接状态。如果失败，再根据具体报错引导用户补充必要信息。

## 常见问题处理

### 连接失败
```bash
# 重启 ADB 服务
adb kill-server
adb start-server

# 重新连接
adb connect <IP>:<端口>
```

### 设备离线
```bash
# 断开后重连
adb disconnect
adb connect <IP>:<端口>
```

### 端口变化
Android 11+ 的无线调试端口可能会在每次开启时变化，需要重新查看并使用新端口连接。

### 5555 方式失效
如果 `adb tcpip 5555` 后仍无法连接：
```bash
adb kill-server
adb start-server
adb devices
adb connect <IP>:5555
```

如果多次失败，再让用户提供当前手机 IP、USB 是否仍连接、以及授权弹窗是否已确认。

## 快速参考命令

- `adb devices`: 查看已连接设备
- `adb devices -l`: 查看设备详细信息
- `adb connect <IP>:<端口>`: 无线连接设备
- `adb disconnect`: 断开所有无线连接
- `adb pair <IP>:<端口>`: 配对新设备
- `adb tcpip 5555`: 切换到无线调试端口 5555
- `adb kill-server`: 重启 ADB 服务

---

## 注意事项

1. **同一网络**：手机和电脑必须在同一 WiFi 网络下
2. **端口变化**：Android 11+ 的端口可能动态变化，每次重连需确认新端口
3. **防火墙**：确保电脑防火墙允许 ADB 连接
4. **首次配对**：Android 11+ 方式需要先完成配对，再执行连接
5. **USB 方式**：`adb tcpip 5555` 需要先通过 USB 让设备进入 TCP/IP 模式
6. **少打扰原则**：在不影响成功率的前提下，优先自动执行、自动验证、自动汇报结果，只有报错或信息缺失时才向用户索取必要信息
